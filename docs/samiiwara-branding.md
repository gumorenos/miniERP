# Samiiwara pilot visual direction

The pilot UI should feel like a quiet operating tool that belongs to Samiiwara, not like a generic ERP and not like an ecommerce storefront.

## Public brand signals used

Public references describe Samiiwara as contemporary garments complemented by Andean embroidery, with an emphasis on colour, craft and Andean textile heritage. Public listings also describe dresses, urban polleras, trousers, skirts and shorts with Andean embroidery.

Those signals are translated into the app rather than copied literally. The operational UI deliberately avoids dense textile patterns or decorative motifs that would compete with data entry and daily use.

## Palette

- Ink / text: `#291F22`
- Warm canvas: `#F7F0E4`
- Paper: `#FFFDF8`
- Berry / primary: `#8F2948`
- Saffron accent: `#D99A2B`
- Turquoise accent: `#287D78`
- Leaf accent: `#5B7B4B`

The berry colour carries primary actions. Saffron, turquoise and leaf are used sparingly as embroidery-like accents and KPI identifiers rather than as large background fields.

## Typography and shape

- System sans-serif for operations and forms.
- Georgia fallback for large headings to add a restrained atelier/editorial note without shipping custom font assets.
- Warm surfaces, moderate radius, low-contrast shadows.
- A narrow four-colour accent bar is the main visual reference to multicolour embroidery.

## Guardrails

- No faux-Andean patterns as decoration.
- No gradients behind data-heavy sections.
- No excessive colour coding.
- Keep mobile workflows and readability more important than branding.
- The business name should be Samiiwara; `miniERP` remains the technical project name only.
